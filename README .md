# Level Up Africa — Quiz

## Description
Quiz interactif sur les startups, inventeurs et success stories de la tech africaine.
Projet réalisé dans le cadre du programme de vacances Level Up Africa, pour consolider
les bases HTML / CSS / JavaScript à travers un mini-jeu ludique et éducatif.

## Fonctionnalités
- Questions à choix multiples générées dynamiquement depuis un tableau JavaScript
- Vérification de la réponse en temps réel (feedback visuel vert / rouge)
- Calcul du score au fur et à mesure du quiz
- Timer par question
- Barre de progression
- Écran de résultats final personnalisé

## Stack technique
- HTML5
- CSS3 (vanilla)
- JavaScript vanilla (aucun framework, aucune librairie externe)

## Installation
1. Cloner le dépôt :
   ```bash
   git clone https://github.com/Ado-2k8/Salon_de_dev.git
   cd Salon_de_dev
   ```
2. Ouvrir le dossier, puis double-cliquer sur `index.html`
   (ou l'ouvrir avec l'extension "Live Server" de VS Code)

Aucune dépendance à installer, aucun serveur requis.
